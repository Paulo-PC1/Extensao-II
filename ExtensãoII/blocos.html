Manual dos Blocos Utilizados nos Diagramas

Este manual apresenta os blocos utilizados nas peças impressas em 3D que serão empregadas durante as atividades de lógica de programação. Cada bloco representa uma etapa específica do algoritmo e pode ser combinado com outros blocos para construir soluções para diferentes problemas.

Os blocos apresentados neste projeto foram selecionados para atender aos exercícios de estrutura sequencial, estrutura de decisão e estrutura de repetição.

Bloco de Início/Fim

Formato do diagrama: Terminal (oval ou arredondado)

Função: indicar o ponto de início ou término de um algoritmo. Todo algoritmo deve possuir um bloco de início e um bloco de fim para delimitar sua execução.

Bloco de Entrada de Dados

Formato do diagrama: Paralelogramo

Função: receber informações fornecidas pelo usuário. É utilizado sempre que o algoritmo precisa ler valores para realizar algum processamento.

Bloco de Processamento

Formato do diagrama: Retângulo

Função: executar cálculos, operações matemáticas ou atribuições de valores. É o bloco responsável por transformar os dados de entrada em resultados.

Bloco de Saída de Dados

Formato do diagrama: Paralelogramo

Função: apresentar ao usuário os resultados produzidos pelo algoritmo. A saída pode exibir valores calculados, mensagens ou informações processadas.

Bloco de Decisão

Formato do diagrama: Losango

Função: avaliar uma condição e determinar qual caminho o algoritmo deverá seguir. Possui normalmente duas saídas:

  • Sim (Verdadeiro)
  • Não (Falso)

Bloco de Repetição (While)

Formato do diagrama: estrutura composta por um bloco de decisão associado ao fluxo de retorno.

Função: repetir um conjunto de instruções enquanto uma condição permanecer verdadeira. Esse bloco será utilizado para representar a estrutura de repetição "Enquanto" (While).

Relação com as Peças Impressas em 3D

Cada peça impressa em 3D representa um dos símbolos utilizados em diagramas de blocos. Durante a atividade, os participantes poderão montar fisicamente os algoritmos propostos, visualizando e manipulando cada etapa da solução.

Essa abordagem busca facilitar a compreensão dos conceitos de lógica de programação por meio de uma experiência prática, interativa e acessível.
